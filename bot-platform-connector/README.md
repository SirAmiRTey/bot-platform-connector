# پلاگین اتصال به پلتفرم ربات

## توضیحات

این پلاگین وردپرس، امکان اتصال فروشگاه ووکامرس به یک بک‌اند لاراول را برای مدیریت ربات‌های تلگرام فراهم می‌کند. این سیستم از دو نوع محصول پشتیبانی می‌کند:

1. **محصولات دانلودی**: کاربران پس از خرید، کد منبع ربات را دانلود می‌کنند
2. **محصولات اشتراکی**: کاربران سرویس میزبانی ربات را خریداری کرده و می‌توانند آن را تمدید کنند

## پیش‌نیازها

- وردپرس ۵.۸ یا بالاتر
- PHP 7.4 یا بالاتر
- ووکامرس ۵.۰ یا بالاتر
- MySQL 5.6 یا بالاتر / MariaDB 10.1 یا بالاتر

## نصب و راه‌اندازی

### روش اول: نصب از طریق پیشخوان وردپرس

1. فایل پلاگین را فشرده (ZIP) کنید
2. به مسیر **افزونه‌ها > افزودن > بارگذاری افزونه** بروید
3. فایل ZIP را انتخاب و آپلود کنید
4. پس از نصب، پلاگین را فعال کنید

### روش دوم: نصب دستی

1. پوشه `bot-platform-connector` را در مسیر `wp-content/plugins/` آپلود کنید
2. به پیشخوان وردپرس بروید
3. از بخش **افزونه‌ها**، پلاگین "اتصال به پلتفرم ربات" را فعال کنید

### مراحل پس از نصب

1. **تنظیمات اتصال**: 
   - به منوی **ربات پلتفرم > تنظیمات** بروید
   - آدرس API بک‌اند لاراول را وارد کنید
   - کلید امنیتی HMAC را تنظیم کنید

2. **تنظیمات تمدید**:
   - مبلغ پایه ماهانه را به تومان وارد کنید
   - درصدهای تخفیف برای دوره‌های مختلف را تنظیم کنید

3. **تنظیمات ایمیل**:
   - گزینه‌های ارسال ایمیل هشدار انقضا را پیکربندی کنید

4. **تنظیمات عمومی**:
   - بازه زمانی همگام‌سازی خودکار با بک‌اند را مشخص کنید

## ساخت محصولات

### ایجاد محصول دانلودی

1. به **محصولات > افزودن جدید** بروید
2. نوع محصول را **متغیر** انتخاب کنید
3. ویژگی‌ها را تعریف کنید (مثلاً نسخه ربات)
4. تغییرات را ایجاد کنید
5. برای هر تغییرات:
   - **نوع ربات**: دانلودی
   - **مدت زمان اشتراک**: 0
   - **شناسه محصول در لاراول**: شناسه محصول در سیستم لاراول

### ایجاد محصول اشتراکی

1. به **محصولات > افزودن جدید** بروید
2. نوع محصول را **متغیر** انتخاب کنید
3. ویژگی‌ها را تعریف کنید (مثلاً دوره اشتراک)
4. تغییرات را ایجاد کنید
5. برای هر تغییرات:
   - **نوع ربات**: اشتراکی
   - **مدت زمان اشتراک**: تعداد روزهای اعتبار (مثلاً 30 برای یک ماه)
   - **شناسه محصول در لاراول**: شناسه محصول در سیستم لاراول

## جداول دیتابیس

این پلاگین دو جدول در دیتابیس وردپرس ایجاد می‌کند:

### جدول `wp_bot_instances`
اطلاعات نمونه‌های ربات فعال کاربران را ذخیره می‌کند:
- شناسه کاربر و سفارش
- توکن و نام کاربری ربات
- وضعیت (در انتظار، در حال اجرا، متوقف شده، منقضی شده)
- تاریخ انقضا
- تعداد تمدیدها

### جدول `wp_bot_downloads`
اطلاعات دانلودهای محصولات دانلودی را ذخیره می‌کند:
- شناسه کاربر، سفارش و محصول
- نسخه انتشار
- لینک دانلود و زمان انقضای آن

## ساختار فایل‌ها

```
│   ├── class-admin-settings.php    # صفحه تنظیمات پلاگین
│   └── class-database.php          # مدیریت جداول دیتابیس
├── languages/
│   └── bot-platform-fa_IR.po       # فایل ترجمه فارسی

```

## هوک‌ها و فیلترها

### هوک‌های اکشن

- `bot_platform_connector_bot_instance_created`: هنگام ایجاد نمونه ربات جدید
- `bot_platform_connector_bot_download_created`: هنگام ثبت دانلود جدید
- `bot_platform_connector_subscription_expiring`: هنگام نزدیک شدن به انقضای اشتراک

### فیلترها

- `bot_platform_connector_api_headers`: اصلاح هدرهای درخواست به API
- `bot_platform_connector_renewal_price`: محاسبه قیمت تمدید با تخفیف

## امنیت

- استفاده از nonce برای تمام فرم‌ها
-_sanitization_ و _escaping_ داده‌های ورودی و خروجی
- بررسی سطح دسترسی کاربران
- استفاده از prepared statements برای کوئری‌های دیتابیس

## ترجمه

پلاگین از متن‌دامنه `bot-platform-connector` استفاده می‌کند. برای افزودن زبان جدید:

1. فایل `.po` را در پوشه `languages/` ایجاد کنید
2. از ابزارهایی مانند Poedit استفاده کنید
3. ترجمه‌ها را ذخیره و فایل `.mo` را تولید کنید
